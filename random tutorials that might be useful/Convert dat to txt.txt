Using the parser to convert .dat to .txt

Take the file from the server folder/script/
and copy it to the folder "gu_unpacker/datsource/ here"
of your parser.

Open your browser and type:
localhost/parser/php2.8/ and run the file "servertotxt.php" — just click it.

It will generate a .txt file that corresponds to the server file.

It will generate it here: "parser/gu_unpacker/txtsource/ here"

Now make your edits using Excel.

After making the edits, you'll need to save it into the folder "parser/gu_in/CashShop.edf/ here"

If it asks to replace, replace it!!!

Now let's create the .dat files for the server and client.

In the browser, go to the url "localhost/parser/php2.8/" run the file cashshop.php, then go back to the previous url and run server.php

There you go, it has now generated the files
CashShop.dat / itemcash.dat / nditemcash.dat

The cashshop file goes to the server/script/ folder here.
The itemcash and nditemcash files go to the folders:
client/dataTable/ here.
client/dataTable/en-gb/ here.

Note: if your dataTable has more folders like en-gb/ pt-br/ ru-ru/, you copy to all of those folders too. They're the server's languages.

Now let's grab the files generated by the parser.

itemcash.dat is in the folder "parser/gu_out/CashShop.edf/

cashshop.dat and cashshop_str.dat are in the folder "parser/gu_out/ServerScript/

nditemcash.dat is in the folder "parser/gu_out/en-gb/"
