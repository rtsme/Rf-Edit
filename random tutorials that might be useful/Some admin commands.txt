#################################################

%neverdie 1
%neverdie 0

(put 1 in front to enable or 0 to disable)
"This command makes you invincible"

#################################################

%moncall

(put the monster's code in front to summon the monster to your location)

example: %moncall 0920B

If you want to summon several of the same mob, just add the quantity number after it.

example: %moncall 0920B 5

This will summon 5 mobs matching that code.

#################################################

%gold

(put the value in front to add gold)

example: %gold 5000

You'll receive 5000 gold.

#################################################

%money

(put the value to add dalant)

example: %money 5000000

You'll receive 5kk = 5,000,000 money

#################################################

%matchless 1
%matchless 0

(put 1 to enable or 0 to disable)
"This code makes you kill anything in 1 hit without a skill"

#################################################

%allskill 10000000000

(code to give full skill and GM PT to the character using it — only useful if your server isn't already GM-PT and you want to quickly become GM.)

#################################################

!Good night

This command sends the message "Good night" in chat for all players to see — the popup that appears when the admin is speaking.

Note: always use the ! sign before the message.

%lv65

%bags

#################################################

%*

(put the item's code after it and it drops on the ground)

Example: %*iwspb50

This command will drop a level 50 spear.

The command %* followed by the item's code will drop the item on the ground.

$gm

(put the welcome message all players receive on login after the code)

Example: $gm Welcome to RF Space

This command sets the welcome message shown in general chat when a player logs into the game.

But if you restart the server, this message will be cleared.
