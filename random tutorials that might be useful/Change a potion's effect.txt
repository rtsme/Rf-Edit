Open the file PotionItemEffect.strs using Structorian.

Open the file PotionItemEffect.dat, located in the server's RF_Bin/Script/..... folder.

Using the program "RF Online Codes by Nitemare" you can go to the potions menu and find the potion you want to edit — in this case we'll edit the Gold Capsule +29, which is at index=404.

Now in Structorian, go to index 404, matching the index in "RF Online Codes".

Browsing the side columns we find the column:
m_fTempValue, which has the value 29, meaning that using this capsule gives you 29 gold points — so if we change this value to 100, you'll receive 100 when you use the capsule.

Now just save, replace it in the server's script folder, and restart the server.
